# AI Workspace 试用与变现路径实施计划

## 目标

将首页「免费试用」变为无需注册即可进入的 AI Workspace 体验入口，并用清晰、逐步的权限与产品引导，把用户从临时试用带到注册 Free、预充值按量付费、Pro 订阅与托管服务按量付费。

核心原则：先让用户完成一次真实任务，再在需要保存、下载或更多额度时提出注册与升级；所有任务额度、保存权限、制品下载权限必须由服务端执行，不能只依赖前端限制。

## 实施状态（2026-08-12）

- **已完成第一纵切：** 首页中英文「免费试用」进入 `/ai-workspace?entry=trial`；该入口复用实际 XWorkmate 编辑器，不再进入旧的总览壳层。
- **已完成匿名试用闸门：** 服务端发放签名 HttpOnly Cookie，默认 5 次任务额度；执行请求只能通过受限试用通道，并携带临时执行标记；额度用尽返回注册引导。
- **已完成基础注册回跳：** 试用页的注册入口通过受校验的 `returnTo` 回到 Workspace，注册后登录跳转不允许开放重定向。
- **待接入账户服务：** 注册 Free 7 天、每日 5 次、会话持久化与制品下载的正式 entitlement/ledger 契约。
- **待接入计费服务：** ¥5/¥10/¥20（或 $5/$10/$20）充值、Pro/XConnect、托管服务按量扣费与退款规则。

当前匿名 Cookie/IP 计数是单进程 MVP；多实例生产环境必须迁移到共享的 entitlement/rate-limit 服务，并配置 `AI_WORKSPACE_TRIAL_SECRET`，再开启全量流量。

## 用户路径

```text
首页「免费试用」
  → /ai-workspace（访客试用，免注册）
  → 达到试用限制 / 尝试保存会话 / 尝试下载制品
  → 注册账号（7 天 Free 使用期）
  → 日额度用尽 / 需要更高运行额度
  → Pay as you go 预充值（¥5 / ¥10 / ¥20；或 $5 / $10 / $20）
  → 需要私有环境连接或中国大陆 AI 服务加速
  → Pro 订阅（含 XConnect）
  → 需要托管资源或套餐额度耗尽
  → 托管服务按量付费
```

## 方案与权限矩阵

| 阶段 | 身份与入口 | 任务额度 | 会话与任务 | 制品 | 主要引导 |
| --- | --- | --- | --- | --- | --- |
| 访客试用 | `/ai-workspace`，无需注册 | 每个匿名试用身份 3–5 次任务；首期实现固定为 **5 次**，后续可实验调整 | 不保存、不支持持久化任务；刷新或离开后不保证恢复 | 不可下载 | 「注册后保存会话与下载制品」 |
| 注册 Free | 注册后自动开通 7 天使用期 | 每日 5 次任务（需配置化，可在 3–5 范围调整） | 可保存会话与持久化任务 | 可下载已生成制品 | 「充值获得更多运行额度」与三端连续工作介绍 |
| Pay as you go | 已注册、账户余额大于 0 | Free 日额度外按任务/运行量扣余额 | 与 Free 相同 | 与 Free 相同 | 「升级 Pro，连接私有环境与获得 AI 服务加速」 |
| Pro 订阅 | 已注册、有效订阅 | 订阅包含额度；超出按既定规则提示或计费 | 与 Free 相同，提供更高协作与连接能力 | 与 Free 相同 | XConnect 能力与托管服务引导 |
| 托管服务按量付费 | 已注册、满足余额或计费授权要求 | 按托管资源与实际用量计费 | 持久化 | 可下载 | 在套餐额度/订阅额度用尽时显示 |

> 「同一 IP」仅作为风控信号，而不是唯一计数键：NAT、企业网络及隐私代理会导致误伤。匿名试用应以 HttpOnly 匿名试用 Cookie 为主键，结合 IP 前缀、UA 哈希与速率限制作为防滥用信号；达到高风险阈值时要求注册，而不是无限制封禁整段 IP。

## 关键产品规则

### 1. 访客试用

- 首页和未登录导航的「免费试用」均跳转 `/ai-workspace`，不再跳 `/register`。
- 初次进入服务端发放不可预测的、HttpOnly、SameSite=Lax 的匿名试用 Cookie；不得把可伪造的剩余额度放在 localStorage。
- 访客可以新建并执行任务，但默认固定 **5 次任务**；额度、周期、模型/工具白名单均由服务端配置。
- 访客会话只允许运行期临时上下文：不写入用户持久命名空间，不进入跨端会话列表，不支持恢复。
- 访客无制品下载接口权限；如果任务产生预览，页面可展示受控预览，下载行为触发注册引导。
- 在第 3 次任务完成后显示轻提示；第 5 次开始前、保存会话、下载制品时显示阻断式注册引导。
- 访客任务应标记 `trial` 来源、匿名试用 ID 和风控信号，保留最短必要审计时间；过期临时数据由后台清理。

### 2. 注册 Free（7 天）

- 注册成功后将当前访客路径带回 `/ai-workspace`，并显示「已开启 7 天 Free 使用期」。
- 注册不是购买：不强制绑定套餐、不要求充值、不要求支付方式。
- Free 账户每日固定 **5 次任务**（默认值；保留服务端配置为 3–5 次的实验开关）。
- Free 可保存会话、创建持久化任务、下载制品；显示剩余任务次数、重置时间和使用记录入口。
- Free 完成首个持久化任务后，引导了解「在 Web、Desktop、Mobile 之间保持工作连续」：以现有三端预览区和下载入口为证据，不承诺尚未实现的自动同步能力。

### 3. Pay as you go（预充值）

- 在账户页/额度用尽弹窗提供快捷档位：人民币 `¥5 / ¥10 / ¥20`；美元 `$5 / $10 / $20`。
- 币种由结算地区、账户默认币种或支付通道能力决定；一个订单只使用一种币种。
- 充值、余额、扣费、退款、失败支付均由账户/计费服务维护账本；前端只读取余额与可购买档位。
- 上线前必须定义任务/运行计费单位、每次扣费时点、失败任务是否退回额度、余额不足时的处理和税费展示。未定义前，不得把 Free 日额度自动映射为余额扣费。

### 4. Pro 订阅与 XConnect

- Pro 升级页应清楚说明：XConnect 可连接用户的私有环境与服务；面向中国大陆用户提供 AI 服务连接加速能力。
- 文案避免“连接一切”的绝对承诺；列出支持的连接方式、所需客户端/Connector、权限边界与地区适用范围。
- Pro 的包含额度、超额规则、月付/年付价格和是否可与余额并用，必须由计费目录作为唯一来源。
- 触发时机：用户连接私有环境、尝试使用加速服务、连续多日触及 Free 上限、或主动打开升级入口。

### 5. 托管服务按量付费

- 当 Pro 包含额度或套餐额度用尽、或用户选择部署托管资源时，展示「托管服务按量付费」。
- 延续现有定价页定义：按资源规格与实际使用量收费，并在适用时收取托管服务费；最终价格、保留期和暂停规则由计费目录/账本返回。
- 不允许仅凭前端“升级成功”状态开通资源。资源创建前，服务端必须验证用户权限、可用余额/信用额度和计费状态。

## 技术边界与现状

当前 `/ai-workspace` 已接入实际 XWorkmate 编辑器；已登录任务继续通过普通 Bridge 代理，匿名任务通过新增 `/api/ai-workspace/trial` 受限转发到 `xworkmate-bridge`。会话 BFF 当前要求账户会话令牌，因此匿名试用不能直接复用持久会话接口。

实现时需要新增一个受限的访客执行通道，而不是放开现有认证会话接口：

```text
Browser
  → /ai-workspace（访客 UI）
  → Trial gate（匿名 Cookie、额度、风控、功能权限）
  → 受限 Bridge trial namespace（临时会话、工具/模型白名单）
  → 任务运行

Registered user
  → 认证会话 BFF
  → Account/Billing entitlement gate
  → 持久命名空间与制品存储
  → Bridge / XConnect / 托管资源
```

禁止的实现方式：

- 仅在 `ChatInputArea` 内用 localStorage 计数。
- 只按完整 IP 作为试用身份。
- 在前端隐藏下载按钮但仍保留未授权下载 URL。
- 用匿名身份调用完整持久会话、任意 Connector、任意模型或任意文件导出接口。

## 分阶段实施

### P0：决策与计费契约（先完成）

1. 确认首期访客任务额度为 5 次、注册 Free 每日额度为 5 次；将两者放入服务端配置，支持后续在 3–5 范围调整。
2. 定义「一次任务」的唯一计数事件：建议在 Bridge 接受可执行 run 时扣 1 次；因平台错误被拒绝的 run 不扣；用户取消后的规则单独明确。
3. 定义 Free 7 天的起点（注册完成时）与到期后的基础权益；确认是否仍保留每日 5 次或改为只读/按量。
4. 由账户服务确认账本、预充值 SKU、币种、Stripe/支付通道、退款和对账 API 合约。
5. 由 Bridge 团队确认匿名 trial namespace、临时数据 TTL、模型/工具白名单、并发和速率限制。
6. 由产品/法务确认匿名风控数据与留存周期，以及对 AI 任务输入/制品的隐私告知。

验收：形成版本化 entitlement API 契约和事件字典；无未定义的自动扣费或无限制匿名执行路径。

### P1：访客试用（最小可用）

1. 更新首页 CTA 与未登录导航 CTA，全部跳转 `/ai-workspace?entry=trial`。
2. 新增 Trial entitlement API：发放/读取匿名试用身份、剩余任务、功能权限和注册引导原因。
3. 新增 Trial run API：服务端原子校验额度、风险状态与允许工具后转发至受限 Bridge namespace。
4. AI Workspace UI 显示「访客试用剩余 X/5 次」；保存、下载和第 5 次任务分别展示对应的注册引导。
5. 临时会话/制品使用短 TTL 清理，不进入持久任务列表。
6. 增加匿名任务频率限制、IP 前缀/UA 信号与审计事件。

验收：无登录用户能完成最多 5 次受限任务；第 6 次被服务端拒绝；刷新、伪造前端状态或直接访问下载接口均不能绕过限制。

### P2：注册 Free 与迁移体验

1. 注册 CTA 带回当前来源与引导原因（`save_session`、`download_artifact`、`trial_limit`），不得在 URL 传递任务文本、会话内容或密钥。
2. 注册完成后创建 7 天 Free entitlement，并显示每日剩余任务数与下次重置时间。
3. 开放持久会话、任务恢复和制品下载；对访客期任务明确提示“注册后新任务可保存”，除非 P0 已定义安全的临时任务认领流程。
4. 在首次保存/下载成功后展示三端连续工作引导，链接现有 Web/Desktop/Mobile 产品预览及下载页。
5. 添加日额度、时区、重复注册、账号风控与 entitlement 变更审计测试。

验收：注册不要求购买；注册用户可保存与下载；每天达到上限后有明确余额/升级入口，且不会丢失已保存任务。

### P3：预充值 Pay as you go

1. 在订阅/账单页增加 AI Workspace 预充值商品与 `¥5/¥10/¥20`、`$5/$10/$20` 快捷入口。
2. 接通 checkout、支付回调、账本余额、可用余额查询和失败/取消反馈。
3. 将 P0 定义的任务/运行计费接入服务端 entitlement gate；按幂等 key 记录扣费，任务运行、扣费、退款可追踪。
4. Free 用户超过日额度时可选「明天恢复」或「立即充值继续」，不得误导为强制订阅。
5. 记录充值入口、支付开始/成功/失败、余额不足和使用消耗漏斗。

验收：余额变化可在账本核对；并发请求不会重复扣费；余额不足不会开始可收费任务。

### P4：Pro 与 XConnect 升级

1. 以计费目录驱动 Pro 月付/年付商品、权益与价格，不在首页或客户端硬编码可购买状态。
2. 在私有环境连接、Connector 配置和中国大陆 AI 加速入口展示匹配的 Pro 引导。
3. 展示 XConnect 的连接状态、地区适用提示、权限授权说明和可回退方案。
4. 订阅成功后实时刷新 entitlement；取消、付款失败、宽限期和降级按账户服务状态执行。

验收：仅符合条件的用户获得对应连接/加速能力；Pro 文案、价格和实际 entitlement 一致。

### P5：托管服务按量付费

1. 在资源创建和套餐额度耗尽时提供托管服务按量付费入口，显示估算、计费规则和余额要求。
2. 服务端在创建、扩容、续运行前验证账本与 entitlement；资源用量回写到账本。
3. 实现余额不足的暂停、告警、恢复和保留期，与现有定价页规则一致。
4. 增加成本上限、异常消耗告警、管理端审计和客服处理入口。

验收：托管资源不可绕过计费创建；用户可查看估算、实际消耗、暂停原因和恢复方式。

## 数据、风控与分析

- 事件：`trial_started`、`trial_run_accepted`、`trial_run_blocked`、`trial_limit_reached`、`signup_prompted`、`signup_completed`、`free_day_limit_reached`、`topup_started`、`topup_completed`、`pro_prompted`、`pro_subscribed`、`managed_paygo_prompted`。
- 关键维度：入口来源、地区/币种、匿名或已注册、产品能力、风险结果、任务类别；不得采集原始任务文本作为营销分析维度。
- 指标：访客首任务完成率、访客→注册转化、注册后首个持久任务完成、Free→充值、充值→Pro、Pro→托管按量付费。
- 反滥用：服务器端原子额度扣减、每身份/每 IP 前缀/每设备信号速率限制、并发上限、CAPTCHA/邮箱验证升级策略、异常模式审计。

## 风险与回滚

| 风险 | 控制 | 回滚 |
| --- | --- | --- |
| 匿名试用被刷 | 多信号风控、临时命名空间、模型/工具白名单、服务端原子配额 | 关闭 `trial.enabled`，首页 CTA 回到注册页 |
| IP 误伤 | Cookie 为主、IP 前缀只作风控信号、提供注册恢复路径 | 调低 IP 权重或仅限速不封禁 |
| 未登录数据泄露 | 临时隔离、短 TTL、无下载、无持久列表 | 禁用 trial artifact preview 与临时会话 |
| 计费错误 | 账本幂等、价格目录唯一来源、支付 webhook 对账 | 停止收费任务，保留 Free 和人工补偿流程 |
| 促销文案超出能力 | 仅声明已交付功能；XConnect/加速按地区与能力校验 | 下线对应升级入口或改为候补名单 |

## 完成定义

1. 首页免费试用可匿名进入 `/ai-workspace`，且未登录试用额度、会话、任务与制品限制均由服务端强制执行。
2. 注册成功自动获得 7 天 Free 权益，不要求绑定套餐；Free 每日额度、持久会话与制品下载行为可验证。
3. 预充值、Pro、托管按量付费均有可审计的 entitlement 与账本闭环，且价格/权益来自计费目录。
4. 所有阻断与升级路径都有中英文提示、可访问性支持、事件分析和端到端测试。
5. 任一阶段都可通过配置关闭新权益或回退入口，而不破坏已保存的用户会话与制品。
